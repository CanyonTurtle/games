Compile // cart source ⇆ fragment

Write a cart as a plain object (see AUTHORING.md for every field's meaning and the full opcode table) in the left pane — it compiles automatically, with specific errors if anything's wrong, and the right pane fills in with a playable fragment. Paste an existing link or fragment into the right pane instead and the left pane decompiles it back to source, including a disassembly listing for every hook. Both panes stay in sync either direction. Nothing here touches a server: nothing you type ever leaves this page except into the URL you copy out.
