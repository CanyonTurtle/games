The Urlcade // game authoring API

Build a cart as a plain JS object, encode it, get a URL — that URL is the game. Every link below is raw text, readable directly by a browser, a human, or an agent fetching the URL, with nothing rendered in the way. Start with llms.txt for a machine-oriented index of the same list.

Build a cart

  • AUTHORING.md

    How to build a cart: the object shape, every field's meaning, the opcode table, the hook lifecycle, the map generators. Start here.

  • kernel.js

    The actual encodeCart/decodeCart/opcode table/ assembler/VM/compression, extracted verbatim from the runtime into one dependency-free file. Runs standalone under Node or any JS host — no browser, no network, no build step.

  • fixtures.md

    Known-good (cart description → exact bytes → exact fragment string) examples generated by kernel.js. Check your own implementation against these directly.

Play it / inspect it

  • Play

    The live runtime — five playable cartridges, and an INSPECT button on each that decodes and visualizes any cart (palette, sprites, tiles, map, entities, disassembled hooks), including ones you paste in yourself.

Part of The Urlcade — a self-hosted game authoring API.
