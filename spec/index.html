The Urlcade // spec & design docs

Every link below is raw .md — readable directly by a browser, a human, or an agent fetching the URL, with nothing rendered in the way. Start with llms.txt for a machine-oriented index of the same list.

Ground truth — read this first

  • kernel.js

    The exact encodeCart/decodeCart/opcode table/ assembler/VM/compression, extracted verbatim from the runtime into one dependency-free file. Runs standalone under Node or any JS host — no browser, no network, no build step.

  • fixtures.md

    Known-good (cart description → exact bytes → exact fragment string) examples generated by kernel.js. Check your own implementation against these directly.

Spec & reference runtime

  • DESIGN.md

    The design history: binary cart layout, the stack-machine VM and opcode table, the composable generators (palette/map/HUD/camera), and open design questions, in the order they were built. Narrative, not guaranteed current — see kernel.js above for the literal format.

  • v0-README.md

    What the V0 reference runtime actually built against the spec — real bugs found and fixed along the way, and deliberate scope cuts.
